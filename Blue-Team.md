- Blue Teaming is the practice of defending an organization’s networks and systems from cyber threats.
- Blue Teamers focus on identifying vulnerabilities, monitoring for threats, analyzing logs, and responding to incidents to strengthen the organization's overall security posture.
- Security Log: The most critical for security; records authentication attempts (logon failures/successes), account changes, privilege usage, policy changes, process creation, and object access.

- System Log: Tracks core OS events; logs driver failures, service crashes, boot sequence issues, and general system hardware behavior anomalies.
- Application Log: Captures events generated by applications; records app crashes, service start/stop events, and error messages for issue identification.
- Setup Log: Contains events from software installation and system updates; used for tracking changes to software configuration and installation timelines.
- Forwarded Events: A collection point for events forwarded from other systems; crucial for centralizing logs from multiple hosts for correlation analysis.
- Sysmon (System Monitor): An advanced logging tool providing deep telemetry on process creation, network connections, file creation time changes, registry modifications, and driver loads; essential for detailed forensic investigations.
- Windows Defender Log: Tracks actions taken by the built-in antivirus; logs detections of malicious software, scan results, and actions taken against threats.
- PowerShell Logs: Records command execution in PowerShell; used for detecting suspicious scripts and commands run on the system.
- ETW (Event Tracing for Windows): A high-speed, kernel-level tracing mechanism for deep system and application diagnostics; provides granular telemetry for advanced analysis and can bypass some traditional evasion techniques.

| Event ID | Description | What to Look For | Possible Attacks |
|---|---|---|---|
| 4624 | Successful account logon. | An account successfully logs on to a system. | Credential stuffing success, initial access after an exploit, or valid admin access (often paired with 4625). |
| 4625 | Failed account logon. | An account fails to log on. | Brute-force attacks, password spraying, or an attacker trying stolen credentials. |
| 4648 | A logon was attempted using explicit credentials. | A user account runs a process as a different user (e.g., using runas). | Attempts at lateral movement or privilege escalation using stolen credentials. |
| 4672 | Special privileges assigned to a new logon. | A user logs on and is given special privileges (e.g., as an administrator). | Privilege escalation; a standard user account being granted admin rights. |
| 4688 | A new process has been created. | A process is created. | Malware execution, lateral movement via tools like PsExec, or suspicious script interpreters (PowerShell, cmd.exe). |
| 4689 | A process has exited. | A process terminates. | Can be used in conjunction with 4688 to track the lifecycle of a malicious process. |
| 4720 | A user account was created. | A new user account is created. | Persistence; an attacker creating a backdoor account for future access. |
| 4722 | A user account was enabled. | A disabled user account is enabled. | An attacker re-activating a dormant account for malicious use. |
| 4725 | A user account was disabled. | A user account is disabled. | An attacker disabling a security administrator's account as a diversion. |
| 4726 | A user account was deleted. | A user account is deleted. | An attacker cleaning up their tracks after creating a new account. |
| 4738 | A user account was changed. | Attributes of a user account are modified. | An attacker adding a user to the "Administrators" group or modifying properties for malicious persistence. |
| 4740 | A user account was locked out. | A user account is locked out due to multiple failed logins. | An ongoing brute-force or password spray attack causing account lockouts. |
| 1102 | The audit log was cleared. | Someone has cleared the Security log. | A clear indicator of an attacker covering their tracks after a compromise. |
| 7045 | A service was installed in the system. | A new service is registered with the system. | Often associated with malware persistence where a malicious service is installed on a host. |
