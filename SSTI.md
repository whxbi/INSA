# Server-side template injection

- Server-side template injection is when an attacker is able to use native template syntax to inject a malicious payload into a template, which is then executed server-side.
- what is a template? it's an existing placeholder that changes with whatever the user inputs, for example `<h1>Hello, {{ user.name }}!</h1>` `user.name` here is a template placeholder, and if the user name is `whxbi`, it will print out `Hello, whxbi!`
- an SSTI here could be used by changing the parameter value of `name` into `?name={{7*7}}` so it outputs `Hello, 49`
- this happens when the site directly accepts user's input to the template instead of accepting it as data
- template = A blueprint for output with embedded expressions
- the severity varies on the template the payload was injected to, in this example it isn't really that harmful, but incases, some template could have a vulnerability that leads to RCE, or if not RCE, could simply have access to read and view sensetive data

 ## XSS vs SSTI

| XSS | SSTI |
| client-side | server before HTML is sent | 
| JS | Template engine code (Python, Ruby, Java, Jinja2, Twig, Freemarker, Velocity, ERB. etc.) | 
| Steal cookies, deface pages, hijack sessions | Remote code execution, read server files, RCE |
| Reflected/stored in HTML | The HTML itself is generated by the injection |
